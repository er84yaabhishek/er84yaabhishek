## What I Work On

**Mall Management System**
- **Payment reminder engine:** daily cron computes lease-based due dates and live unpaid balance (`Bill + Debit Note − Credit Note − Receipts`), skips zero-balance accounts, and suppresses duplicate reminders.
- **Accounting console:** overdue KPIs, auto/manual dispatch status, bulk send, and audit timeline.
- **FIFO allocation engine:** distributes partial payments and credit notes across bills chronologically.
- **Utility meter register:** Grid/DG consumption with tariff slab escalation.

**Hotel Management System**
- **Housekeeping:** room cleaning state machine, turnover cycles, availability matrix, key tracking.
- **Maintenance:** issue reporting, work orders, and asset repair lifecycle.
- **Queued invoicing:** background jobs that send guest notifications with on-the-fly PDF invoices.

**Vue 3 + TypeScript SPAs**
- 3 SPAs using Pinia and Vite, backed by Laravel REST APIs with Sanctum auth.
